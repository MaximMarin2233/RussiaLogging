# Next.js Project

## Требования

Для корректной работы проекта необходимо:

* **Node.js** версии **18 или выше**

---

## Установка и запуск проекта

### 1. Клонирование репозитория

```bash
git clone <URL_РЕПОЗИТОРИЯ>
```

Перейти в директорию проекта:

```bash
cd russia-logging
```

---

### 2. Установка зависимостей

```bash
npm install
```

---

### 3. Переменные окружения, копировать .env.example в .env.local (.env.production для продакшена)

```bash
cp .env.example .env.local
```

### 4. Запуск проекта в режиме разработки

```bash
npm run dev
```

После запуска проект будет доступен в браузере по адресу:

```
http://localhost:3000
```

---

## Скрипты

В проекте доступны следующие команды:

* `npm run dev` — запуск проекта в режиме разработки
* `npm run build` — сборка production-версии проекта
* `npm run start` — запуск production-сборки
* `npm run lint` — запуск ESLint для проверки кода
